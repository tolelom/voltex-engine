# v1.0 Public-API Audit — `pub(crate)` Downgrade Candidates

**작성일**: 2026-05-21 (Cycle 13, A)
**상태**: Notes only — no code change. v1.1 의 점진 downgrade 작업 자료.

본 문서는 Cycle 13 의 spec § 5.1 (pub(crate) downgrade 후보 식별 — 강제 변경
은 안 함, 후보 목록만 기록) 의 산출물이다. v1.0 release 직전에 외부 API 표면
을 줄이고 싶을 때 가장 먼저 검토할 항목들을 모은다.

## 우선순위 분류

| 등급 | 의미 | 처리 |
|---|---|---|
| **A** | 명백히 내부 — 외부 사용처 없음, `pub(crate)` 또는 `pub(super)` 로 안전하게 다운그레이드 가능 | v1.1 1차 작업 |
| **B** | 모호 — 내부에서만 쓰지만 third-party crate 가 의존할 가능성 약간 있음 | v1.1 검토 후 deprecation cycle |
| **C** | 유지 — 명백한 public API | 다운그레이드 안 함 |

## 후보 (현 시점 grep 기반 1차 stab)

본격적인 감사는 다음 워크로드 가 필요:
1. 각 crate 의 `pub` 항목을 `cargo doc` 출력에서 추출
2. 다른 crate / examples / docs 에서 import / use 하는지 grep
3. 외부 사용처가 0 이고 trait impl 시그니처에 노출되지 않으면 A 등급

현 시점 의심 후보 (자세한 검증은 v1.1 단계):

### voltex_audio
- `wasapi::WasapiDevice` — `backend::WasapiBackend` 가 thin wrapper. 외부 사용처 0 으로 추정 → A.
- `mixing` 내부 helper 함수 다수 (`mix_sounds`, ...) → B (테스트가 직접 참조)

### voltex_renderer
- `deflate` / `png` / `jpg` / `gltf` 의 low-level 파서 진입점 — 단일 `parse_*` 만 외부 노출이 정석. 보조 함수가 `pub` 으로 흘러나갔다면 A.
- `light_probes` 내부 helper → B
- shader 모듈 const 들 (`mesh_shader::SHADER_SRC` 등) → B

### voltex_editor
- `panels::inspector::sync_from` (E3 에서 변경) — public 일 필요 없음, A.
- `gizmo` 내부 hit-test helper — `pick_entity` 외에는 내부 → A.

### voltex_ecs
- `sparse_set::SparseSet` / `ComponentStorage` trait — 의도된 public (Component trait 의 직렬화/디시리얼라이즈가 World 의 storage 시그니처를 알아야 함). C 유지.
- `binary_scene` 의 byte-level reader/writer helper — A.

### voltex_renderer_ecs / voltex_runtime / voltex_cli
- 자체 표면이 작음, 1차 라운드에서는 변경 후보 거의 없음. C 유지.

### voltex_script
- `ffi::*` — Lua C API 의 raw FFI. 외부 사용처 없음, A (지금이라도 `pub(crate)`).

## 검토 방법 (v1.1 첫 세션)

```bash
# 1. 각 crate 의 공개 항목 dump
cargo doc --workspace --no-deps
# target/.../doc/<crate>/all.html 에서 항목 추출

# 2. 외부 사용처 검사 (예: voltex_audio::WasapiDevice)
grep -rn "WasapiDevice" crates examples docs

# 3. zero 사용처면 즉시 pub → pub(crate) (또는 pub(super))
```

## 검토 시 주의

- `Component` trait 의 `serialize` / `deserialize` 시그니처가 `World`, `Entity` 를 인자로 받는 이상 두 타입은 외부 공개 필수 (다운그레이드 금지).
- `EditorCommand` variants 의 필드 (`entity`, `position`, ...) 는 명시적 외부 사용 — public 유지.
- 모든 facade `voltex::prelude` 항목은 자동으로 public — 다운그레이드 금지.

## v1.0 시점 의사 결정

v1.0 은 "공개 API 가 굳음" 이 기준 (rustdoc 100% + breaking change lock). 그러나
"공개 API" = 현재 pub 상태의 모든 항목으로 간주한다. 본 문서의 A 등급 후보들도
v1.0 에서는 그대로 둔다 — `pub` 에서 `pub(crate)` 로 줄이는 것도 breaking change
이고, v1.0 안정성 약속에 어긋난다.

대신 v1.1 의 첫 작업으로 본 문서의 A 등급 후보를 일괄 다운그레이드한다.
