`crates/voltex_audio/src/lib.rs` 끝에 추가:

```rust
pub use vorbis::decode_vorbis;
pub use ogg::parse_ogg;

/// Decode an in-memory OGG/Vorbis byte slice into an AudioClip.
/// Composes `ogg::parse_ogg` + `vorbis::decode_vorbis`.
pub fn decode_ogg_vorbis_bytes(data: &[u8]) -> Result<AudioClip> {
    let packets = ogg::parse_ogg(data)?;
    vorbis::decode_vorbis(&packets)
}
```

Vorbis decode 테스트는 같은 모듈 안에 있어야 하므로, `vorbis/mod.rs` 안에서 `crate::decode_ogg_vorbis_bytes` 호출.

## 알려진 위험

- **Vorbis decode 가 실제 .ogg 파일을 처리할 수 있는지는 v1.0.9 범위가 아님** — 단위 테스트가 통과한다고 실 파일 디코드가 보장되지는 않음 (decode_vorbis 자체가 simplified — scalar codebook only, no coupled channels). 실 파일 검증은 별 cycle.
- **clippy 자동 fix 가 vorbis 수식 인덱스를 부서뜨릴 가능성** — Vorbis 는 spec § 의 인덱스 표현을 그대로 옮긴 코드라 idiomatic iterator 변환이 가독성을 떨어뜨릴 수 있음. 이 경우 `#[allow]` 가 정답.
- **27 → 0 가 아니라 27 → ~20 + #[allow] 5건** 으로 끝날 수 있음. 그래도 `-D warnings` 통과면 v1.0.9 의 게이트 통과. CHANGELOG 에 솔직하게 적기.
