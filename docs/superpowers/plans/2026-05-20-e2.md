# Cycle 4 (E2) — Play/Stop + Lifecycle Hooks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Play 모드에서 World 시뮬레이션 + Stop 시 snapshot 복원. 모든 dispatch 가 Play 중 ModeMismatch 거부. Lifecycle 콜백 (PlayStart/PlayStop) 으로 후속 cycle 의 system attach 인프라 제공. editor_demo 에 RigidBody 떨어지는 데모.

**Architecture:** `EditorSession` 에 `mode: EditorMode` + `play_snapshot: Option<Vec<u8>>` 추가. `set_mode(EditorMode)` 가 Edit→Play 시 `serialize_scene_binary` 로 snapshot, 콜백 호출, undo/redo 클리어; Play→Edit 시 콜백 → `World::clear()` → deserialize. `dispatch` 가 Play 모드에서 `Err(ModeMismatch)` 반환. 미등록 컴포넌트 (RigidBody/Collider) 는 snapshot 에 들어가지 않으므로 Stop 시 자동 소멸 — Play 중 추가한 physics state 가 자연 복원되는 효과.

**Tech Stack:** Rust 2021, voltex_ecs (binary scene + ComponentRegistry), voltex_physics (RigidBody/Collider/physics_step), voltex_editor.

**Spec:** `docs/superpowers/specs/2026-05-20-e2-play-stop-lifecycle-design.md`

Add to `impl EditorSession`:

```rust
    /// Transition between Edit and Play. Edit→Play captures a binary
    /// snapshot of the world; Play→Edit clears the world and deserialises
    /// the snapshot. Both transitions clear undo/redo history. Same-mode
    /// calls are a no-op.
    pub fn set_mode(&mut self, target: EditorMode) {
        if self.mode == target {
            return;
        }
        match (self.mode, target) {
            (EditorMode::Edit, EditorMode::Play) => {
                self.play_snapshot = Some(
                    voltex_ecs::serialize_scene_binary(&self.world, &self.registry),
                );
                self.mode = EditorMode::Play;
                self.undo_stack.clear();
                self.redo_stack.clear();
            }
            (EditorMode::Play, EditorMode::Edit) => {
                self.world.clear();
                if let Some(data) = self.play_snapshot.take() {
                    let _ = voltex_ecs::deserialize_scene_binary(
                        &mut self.world, &data, &self.registry,
                    );
                }
                self.mode = EditorMode::Edit;
                self.undo_stack.clear();
                self.redo_stack.clear();
            }
            _ => {}
        }
    }
```

```rust
//! Lifecycle hooks — callbacks fired by EditorSession on Edit↔Play mode
//! changes. Cycles after E2 (script systems, audio, etc.) register callbacks
//! here to attach/detach simulation state without touching EditorSession.

use voltex_ecs::World;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum LifecycleEvent {
    /// Fired right after the editor transitions Edit → Play, with the
    /// snapshot already captured and the mode already set to Play.
    PlayStart,
    /// Fired right before the editor transitions Play → Edit, before
    /// World::clear() so the callback can still read live state if needed.
    PlayStop,
}

/// A registered lifecycle callback. Boxed so EditorSession can hold a
/// heterogeneous list. Closure receives a mutable World reference so the
/// callback may add/remove components (RigidBody, Collider, etc.).
pub type LifecycleCallback = Box<dyn FnMut(LifecycleEvent, &mut World) + 'static>;
```

In `impl EditorSession`:

```rust
    /// Register a callback fired on every PlayStart/PlayStop transition.
    /// Callbacks run in registration order; a panicking callback aborts the
    /// remainder of the firing pass (panic-as-bug policy).
    pub fn add_lifecycle<F>(&mut self, callback: F)
    where
        F: FnMut(crate::lifecycle::LifecycleEvent, &mut World) + 'static,
    {
        self.lifecycles.push(Box::new(callback));
    }

    fn fire_lifecycle(&mut self, event: crate::lifecycle::LifecycleEvent) {
        let mut callbacks = std::mem::take(&mut self.lifecycles);
        for cb in &mut callbacks {
            cb(event, &mut self.world);
        }
        // Preserve any callbacks registered during the fire.
        let added_during_fire = std::mem::take(&mut self.lifecycles);
        callbacks.extend(added_during_fire);
        self.lifecycles = callbacks;
    }
```

```markdown
## Play / Stop modes (E2)

- `EditorMode { Edit, Play }` — the editor's user-facing state.
- `EditorSession::set_mode(target)` — Edit↔Play transition. Edit→Play
  captures a `serialize_scene_binary` snapshot, fires `LifecycleEvent::PlayStart`,
  clears undo/redo. Play→Edit fires `PlayStop`, wipes the World, deserialises
  the snapshot, clears undo/redo.
- `EditorSession::add_lifecycle(closure)` — register a callback receiving
  `(LifecycleEvent, &mut World)`. Called in registration order at each transition.
- Dispatch in Play mode returns `EditorError::ModeMismatch` — UIs should disable
  mutation controls in Play.
- **Non-registered components vanish on Stop.** Snapshot only carries
  ComponentRegistry-registered types (Transform, Tag, MeshHandle,
  MaterialHandle, Bounds, plus anything games call `register::<T>()` on).
  RigidBody / Collider / Velocity are intentionally NOT registered, so Play-
  mode physics state is automatically thrown away on Stop. Register game-side
  components that should survive.
```
