## Session 1: ScriptComponent + Pool + system_* + spinner.lua

### 1.1 voltex_ecs::script_component
- 신규 파일 `crates/voltex_ecs/src/script_component.rs`

- `Component` trait impl: NAME = "script", serialize = `[u32 instance_id LE][UTF-8 path]`, deserialize 역

- `pub mod script_component; pub use script_component::ScriptComponent;`

### 1.3 voltex_ecs::World::live_entities + EntityAllocator helper
- `EntityAllocator::live_entities() -> impl Iterator<Item = Entity> + '_` — generation table 과 free 상태 확인하여 alive 만 반환
- 기존 `EntityAllocator` 의 내부 구조 (free_list 가 Vec<u32> 인지 HashSet 인지) 확인 후 가장 단순한 방법으로 구현
- `World::live_entities() -> impl Iterator<Item = Entity> + '_` 가 alllocator 의 메서드 위임

### 1.6 voltex_script::pool
- `crates/voltex_script/src/pool.rs` 신규
- `ScriptInstancePool { instances: HashMap<u32, ScriptInstance>, path_to_id: HashMap<String, u32>, next_id: u32 }`
- 메서드:
  - `new()` / `Default`
  - `get_or_create(&mut self, path: &str, world: *mut World) -> Result<u32>`
  - `get(id) -> Option<&ScriptInstance>` / `get_mut`
  - `find_by_path(path) -> Option<u32>`
  - `len()` / `is_empty()`
  - `reload(&mut self, path: &str) -> Result<bool>`
  - `clear(&mut self)` — instances/path_to_id 비우고 next_id = 0
- 테스트 #4 (get_or_create same path), #5 (loads lua file)

### 1.7 voltex_script::system
- `crates/voltex_script/src/system.rs` 신규
- `script_start_all(world, pool)` — 동작은 spec § 3.4 그대로. Vec 수집 후 인스턴스 확보, instance_id 갱신, on_start 호출
- `script_update_all(world, pool, dt)` — 시작된 인스턴스에만 on_update 호출
- `invoke_callback(lua, name, entity, dt: Option<f32>)` — `lua_getglobal` + `lua_pushnumber` × 2~3 + `lua_pcall(L, nargs, 0, 0)` + 실패 시 스택에서 메시지 pop
- 테스트 #6 (reload resets started), #7 (start_all invokes on_start), #8 (update_all started only)
