## Session 2: RuntimeApp + tick_systems_only + winit handler

### 2.1 src/app.rs — RuntimeApp 구조체
- 필드 (drop 순서 의도적으로 정렬):
  - runtime_state: Option<RuntimeState>
  - user_systems: Vec<Box<dyn FnMut(&mut World, f32) + 'static>>
  - file_watcher: FileWatcher
  - timer: GameTimer
  - input: InputState
  - physics_config: PhysicsConfig
  - script_pool: ScriptInstancePool   # World 보다 위 = 먼저 drop
  - assets: RenderAssets
  - registry: ComponentRegistry
  - world: World                       # 마지막
  - config: RuntimeConfig
- RuntimeState struct (private): window, gpu, renderer, camera, camera_uniform, camera_buffer, fps_controller

### 2.2 RuntimeApp::new(config) -> RuntimeResult<Self>
- ComponentRegistry::new + register_defaults
- 사용자 register_components 콜백
- World::new
- initial_scene 로드 (silent 실패 OK)
- build_scene 콜백
- 사용자 setup_systems 콜백 (RuntimeApp 자체에 &mut 접근)

### 2.3 RuntimeApp::add_system
- 사용자 `FnMut(&mut World, f32) + 'static` 시스템 등록

### 2.4 RuntimeApp::tick_systems_only(dt)
- propagate_transforms
- if config.enable_physics → physics_step
- if config.enable_scripts → script_start_all + script_update_all + script_pool.poll_reload (silent)
- user_systems 순서대로

### 2.5 src/app.rs — RuntimeHandler (winit ApplicationHandler)
- resumed: 첫 호출 시 VoltexWindow + GpuContext + BasicRenderer + Camera + buffer 초기화하여 runtime_state 채움
- window_event:
  - CloseRequested → event_loop.exit()
  - RedrawRequested → dt = timer.tick() (fixed_dt override), fps_controller.update, input.end_frame, tick_systems_only, renderer.render, window.handle.request_redraw
  - else → input.handle_window_event(&event)
- 실제 BasicRenderer::render 시그너처 확인 후 인자 맞춤. 시그너처가 어긋나면 RuntimeState 필드를 조정.

### 2.6 RuntimeApp::run(self) -> RuntimeResult<()>
- EventLoop::new() (WindowInit error wrap)
- RuntimeHandler { app: Some(self) } 생성
- event_loop.run_app(handler)
- Ok(())

### 2.7 단위 테스트
- `#[test] new_runs_register_components_and_scene_builder_in_order` — registry 콜백이 새 컴포넌트 등록 → World 빌더가 그 컴포넌트 부착 → app.registry.find("custom").is_some(), world.entity_count() > 0
- `#[test] tick_systems_only_runs_user_systems_in_order` — counter 캡쳐 closure 2개 등록 → tick 호출 → 순서대로 호출 검증
- (테스트는 GPU 없이 RuntimeApp::new + tick_systems_only 만 사용 — runtime_state 는 None 인 상태에서 동작 가능해야 함)
